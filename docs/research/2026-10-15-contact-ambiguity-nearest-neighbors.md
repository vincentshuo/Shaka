# 接触歧义消歧：最近邻、反例与实施判断

日期：2026-10-15（Asia/Shanghai）。对应 [GitHub #32](https://github.com/v6582374-netizen/Shaka/issues/32)。

**决定：当前不实施新的选择算法，也不以“事件摘要 + 按需探测 + 强代理”申报算法创新。保留一个有条件的实证问题：在现有观测足以恢复接触事实、强代理仍有剩余决策缺口时，显式选择规则是否比强代理和等成本探测更节省可信成功成本。**目前没有 Shaka 的受控效果证据，既不能宣布有收益，也不能宣布该窄问题已被所有先例解决。

本票只交付研究与未来比较协议；没有开发算法、调用模型做效果评测、训练或运行物理实验。它不授权下一阶段实验，也不改变 [领域契约](../../CONTEXT.md) 与 [ADR-0001](../adr/0001-freeze-only-the-physical-research-loop-contracts.md)、[ADR-0002](../adr/0002-reach-first-success-through-one-vertical-slice.md)。经典论文、作者代码及读取范围见[一手来源附录](2026-10-15-contact-ambiguity-primary-sources.md)。下文中的“建议”“应当”“若”均为研究设计，不是已取得的结果。

## 1. 先把研究对象分清

当前任务只要求指定指尖接触黄色按钮并撤离；不要求按钮行程、开盖或设备响应。机器人双脚固定，设备位姿固定，允许契约范围内的机器人底座初态变化。候选执行完命令不是任务成功，新的传感信号也不能未经契约变更替代视觉接触与撤离证据。

“消歧”至少涉及三种不同对象：

| 对象 | 能回答的问题 | 不能据此声称 |
|---|---|---|
| 对既有调用的证据查询 | 原始多视角录像中是否已经记录指定指尖接触、随后撤离？ | 放大、插帧或模型补全产生了未采到的物理信息 |
| 对当前状态的主动观测 | 现有可用相机、状态工具能否区分下一步动作所需的状态假设？ | 事后拍到的当前状态证明了已经消失的历史接触 |
| 新的独立物理试验 | 改变可控条件后，下一次调用能否成功，或能否排除某个失败解释？ | 新调用成功可以把上一条 `indeterminate` 改成 `succeeded` |

因此拆成两个估计目标：**旧记录的事实判定质量**与**后续获取可信成功的成本**。离线录像只能直接评估前者，以及某个查询能否提供信息；不能离线重放一条已发生轨迹，就宣称验证了另一种物理试验选择策略的成功率。

还要区分“候选为何失败”的诊断假设与“发生了什么”的事实。接触未被观察到可能是没碰到，也可能是遮挡、采样或同步问题；解释再连贯，也不能把其中一个直接写成因果结论。

## 2. 最近邻已经覆盖了哪些机制

下表是对附录所列一手来源的研究归纳，不把不同机器人、不同监督条件下的论文结果直接迁移为 Shaka 效果。

| 家族 | 已有机制及直接先例 | 对候选新意的压力 | 仍需实证回答的窄差异 |
|---|---|---|---|
| 主动感知与触觉定位 | 根据任务主动改变感知条件；利用接触观测更新物体位姿信念，选择更有信息的动作（附录 S1 Bohg 综述、S2 Javdani 原始研究） | “不确定就换视角/探一下”不是新方法；接触歧义不是全新研究对象 | 在固定 G1/BrainCo 工具和时序验收下，哪些歧义实际可恢复、成本多大 |
| 信息价值 | 用信息对后续决策的期望效用来决定是否获取，而非一味增加信息（附录 S3 Krause/Guestrin） | “预计信息价值减成本”是经典决策原则；熵下降也不等于成功成本下降 | 强模型能否估准动作相关价值，是否比简单规则更好；本票没有这种校准证据 |
| 双重控制 | 动作同时改变任务状态并获取未知系统信息（附录 S4 Klenske/Hennig） | “试一下同时学到东西”已有理论；多步长期价值也非新的框架概念 | 单次尝试、固定复位与中止约束下，独立试验是否存在可利用的辨识价值 |
| 事件触发控制 | 根据状态/误差事件而非固定周期更新控制或通信（附录 S5 作者教程、S6 Antunes/Heemels/Tabuada 原始研究） | “仅在必要时调用模型”并不自动构成创新；S6 已有相同平均传输率比较 | 语言模型的歧义分数不是控制误差界，不能继承原论文的稳定性或触发间隔保证 |
| 机器人代码代理 | Code as Policies 将语言转为可执行反馈程序；VoxPoser/ReKep 源码已有重观测、重规划或回退；REFLECT 用多模态经验摘要解释和修正失败 | 写代码、闭环反馈、事件摘要、反思组合都已有近邻 | 它们不自动提供本任务同资源、独立验收、包含失败成本的比较结果 |
| 自主研究与经验复用 | ENPIRE 冻结环境/验收并保留失败试验；RoboSkill 验证代码与证据引用；现成代理可自主使用工具 | 研究循环、证据包、冻结边界不是新选择算法 | 若强代理已会查证和分配试验预算，外加选择器可能没有剩余效益 |

“没有一个项目正好使用 G1 + BrainCo + 黄色按钮”只说明迁移边界不同，不构成方法新颖性。可成立的贡献至多是新的、可复现的适用边界或成本证据；若要提出算法贡献，还需要明确超出这些近邻的规则、估计方法与结果，目前都没有。

其中最直接的是 Javdani 等人的触碰定位：已按成本选择自适应触碰序列，并与随机、人工固定序列比较。但自动方法选五次、人工序列三次，主要评估定位不确定性，且依赖已知网格、粒子模型和力矩接触观测；不能直接称为本任务完全等成本的可信成功比较。它足以否定宽泛新意，却没有替代本票的四组协议。

以下均于本轮实际读取官方资料，属于厂商能力描述，未调用账户验证，也未在本任务复现。

| 趋势与来源 | 对本票的具体影响 | 不允许的推断 |
|---|---|---|
| [OpenAI 模型目录](https://developers.openai.com/api/docs/models)列 GPT-6 Astra、GPT-6.1 Sol、GPT-6 Luna，并强调推理、代码与图像能力 | 不能以老弱模型或限制工具的模型做唯一 B0；正式实验冻结实际可调用的模型 ID、版本、思考配置和 harness | 名称更先进不能证明在短时接触判断上更准确；本轮不做跨厂商排名 |
| [Claude Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview)已提供 agent loop、工具与上下文管理 | 计划、观察、反思、文件经验是现成基线能力；新增编排必须证明净收益 | SDK 权限配置不等于机器人硬件隔离；会话记忆不等于模型权重学习 |
| [Gemini Robotics ER](https://ai.google.dev/gemini-api/docs/robotics-overview)描述 ER2 的空间/时序推理与工具编排，仍标 preview | 接触事件摘要与机器人推理不能仅靠功能名称宣称新颖；可作为后续第二模型稳健性来源 | 文本/工具编排不等于已具备 G1/BrainCo 的低层接触控制或独立验收 |
| [Gemini 视频文档](https://ai.google.dev/gemini-api/docs/video-understanding)已有 agentic video，按需导航时间线；静态模式默认 1 FPS，文档提示快速变化可能遗漏 | **“选择下一段视频来看”本身已是产品近邻**。B0 应保留同样能力；H 必须胜过它或限定到另一个可测缺口 | 模型按需查帧不能恢复相机未录到的接触；提高采样率的收益不能写成选择策略收益 |

因此应更新前轮“事件不确定性驱动选择”的定位：它是待检验的显式决策约束，未证明强模型缺少它。若只有特定弱模型需要该规则，结论必须缩为该模型/成本档位，不能泛化为强代理必需机制。

## 5. 三类歧义必须由什么证据区分

分类相对于**冻结的传感器、查询/动作集合、时间范围和预算**，不是物理世界的永恒属性。模型说“不确定”只是筛查信号，不是可恢复性标签。独立审校者看不到策略组别、模型自信或摘要结论；人工标签只用于隔离验收/一次性评估器开发，不回流在线策略。

| 类别 | 任务例子 | 分类需要的实际证据 | 应有行为 |
|---|---|---|---|
| 无歧义 | 当前证据清楚显示正确指尖接触且撤离，或明确未接触/错误指尖 | 同步连续原始视角、可辨接触面与撤离段；独立审校一致，传感/记录健康 | 无需额外探测；H 的额外调用与延迟是负效益，必须计入 |
| 可恢复歧义 | 已呈现的低采样片段遮挡，但同一调用已录制的另一视角或高帧率片段清楚记录事件 | 在预先允许的查询中，实际找到能区分竞争假设的原始证据；盲审验证查询前后判定改变有事实根据 | 查询证据，保留时间引用；摘要/帧选择不得伪造事实。若要靠新动作，只能作为当前状态判断或新 invocation 的信息 |
| 当前条件下无法恢复 | 所有可用录像在接触时刻均遮挡/丢帧，撤离后外观相同；或有用查询超过预算 | 审计可用通道、时间同步、采样、遮挡及允许查询；给出与现有记录均相容的“碰到/未碰到”解释。对未遍历工具只能标“恢复性未知” | 旧调用保留 `indeterminate`；允许的下一次尝试另记。不能用多数模型投票、重写解释或新调用结果补成旧成功 |

无法凭有限测试证明全物理空间“绝不可能恢复”，所以使用上述有界表述。新的传感器能使未来调用可观察，不会改变已丢失的历史记录。没有原始接触真值时，不把未知样本硬分为成功/失败；单独报告未知比例，并做最有利/最不利边界分析。

正式组间比较同时报告全部自然样本和这三层的结果。不能只挑可恢复遮挡样本；也不能按 H 是否成功恢复来事后定义“可恢复”。分层由独立证据审计建立，审计额外信息不反馈给候选。

## 6. 四组可归因比较

### 6.1 共享条件

四组冻结同一强模型快照、harness、提示的共同任务部分、基础候选版本、传感器及标定/同步/采样、原始记录访问权、工具参数范围、控制入口、reset、硬件保护、独立验收器与五态语义。共同提供本体说明、时间戳、失败历史和既有经验；不向某一组偷偷提供目标坐标、接触真值或人类诊断。

“同样原始信息”指相同初始证据及同等获取权，不要求不同物理试验产生字节相同的未来轨迹。离线证据比较可以共享同一记录；在线比较用相同初态分布、随机分组/平衡顺序与独立调用，避免把另一组已取得的目标域试验免费交给 H。分组间记忆与候选修改隔离。

预算为多维上限：物理尝试数、机器人占用时间（含观察/复位）、模型和其他计算费用/时间、人工分钟、总墙钟时间。所有组面对同一上限；**上限相同并不代表实际花费相同**，实际使用向量必须同时报告。若要折为单一成本，预先固定权重/价格并做敏感性分析，不在看到结果后改变机器时间与 token 的兑换比例。

### 6.2 组别与解释

| 组别 | 唯一预定差异 | 能回答的问题 |
|---|---|---|
| B0：强代理原始证据 | 直接获取完整原始证据和同一工具，使用合理原生配置，可自行写程序、总结、查帧、选择探测；不注入额外事件摘要/选择规则 | 原生强代理是否已足够？不得禁用其主动查证能力来“做强”H |
| B1：事件摘要 | B0 + 从同一原始记录自动提取的事件/歧义摘要；保留原始证据访问，无新增监督 | 表示是否有用？摘要提取/调用/开发成本单列并计入，B0 自己做的总结同样计费 |
| B2：等成本固定/随机探测 | 同 B1 的摘要；预注册触发时机与可行动作集合，以固定轮转或记录种子的随机规则选择。固定、随机作为两个子对照分别报告，不混为一个均值 | 多查一次或试一次本身是否足够？固定规则须合理，不能故意探测无关区域 |
| H：选择性探测 | 同 B1 的摘要；显式依据竞争假设及预计决策价值选择查询、独立试验或停止。选择计算也付费 | 在信息、工具、预算公平时，显式选择比 B0/B1/B2 增益多少？ |

B2 与 H 的**主对比**使用相同决策机会、相同最多探测数与预先定义的成本档位；在同一档位内比较“选哪个”。另设整个策略比较允许 H 选择“何时探测/停止”，画实际成本—可信成功曲线，不能把“少调用了几次”的效果全解释为选对动作。B0/B1 的自然工具使用照实记录，不人为削弱。

实际物理成本不可事先精确配对：固定/随机动作也可能导致不同复位时间。使用事前成本分档和统一硬上限，报告实际差额；不能声称预算相同就已经完成“等成本”控制，更不能按 H 的事后成功轨迹给 B2 挑便宜样本。若档位内差额仍大，结论限定为预算约束下整体策略比较，不能宣称纯选择效应。

四组均不得获得额外人工标签、独享传感器、免费模型调用或更多接触次数。新增传感器必须四组共同提供，并另作传感器前后消融；新增训练/计算/历史试验全部算入开发或运行成本。固定规则的调参预算与 H 的调参预算一致，正式留出集不可调规则。

### 6.3 物理边界

每次新的接触尝试是新的 single-attempt invocation，拥有独立证据与预算记录。一个“诊断工具”内部反复触碰不允许算一次调用。读旧帧不计新物理尝试，但占计算/查询时间；移动相机或机械臂不是免费的“只读查询”，须在实际可用工具、执行保护与占用时间中声明，本票不假定这些动作已实现。

`failed` / `indeterminate` 后遵循候选外的固定复位；`aborted` 停止自主链，不能为了凑样本自动续跑。自动结果为 `succeeded` 时按 ADR-0002 暂停并人工确认；一个 0→1 研究过程到首次可信成功即结束。可靠性或多初态统计属于另行批准的独立研究过程，不能暗中延长本轮自主运行。

## 7. 怎样避免“成功样本平均成本”误导

分析单位是预先分配预算的研究过程/初态，而非单条成功录像。包含所有被分配过程及其全部 invocation；报告 `succeeded`、`failed`、`indeterminate`、`aborted`、`abstained`，外加预算耗尽和基础设施异常标记。任何异常不能静默剔除；若允许另报部署健康子集，也必须保留全分配主结果与排除原因。

主要联合终点：

1. **给定预算内至少一次独立确认的可信成功比例**，同时报告未完成比例与置信区间。模型自报成功不计。
2. **误验收**：已验收成功但独立原始证据审校否定的次数，分别除以全部分配过程及全部验收成功；无法审清的验收另列，不能按无误验收处理。若独立视觉证据也不足，报告可判定范围与最坏界限，不声称已知真实误验收率。
3. **成本向量**：每个过程的物理尝试、机器人秒数、复位/人工分钟、模型与其他计算费用、墙钟时间；失败和超预算过程照算已花费成本。禁止只报成功组平均值。可另报截至共同预算的成功累计曲线，耗尽预算为未成功而非删失掉；仅在明确的生存分析方案中处理行政截尾。
4. **不确定、弃权、保护中止与额外探测开销**，分别看三类歧义和总体。保守弃权可以降低误验收，也会降低覆盖，必须一起看。

不能预设一个没有数据支持的样本量或宣称“零误验收证明安全”。后续先用独立试点估计基线、变异、歧义占比与可负担样本量，再预注册最小有意义成本改善、误验收非劣界限、统计方法、重复初态的聚类单位、最大预算及停止规则。若资源不足以把误验收上界压到允许范围，结论应为证据不足，而不是“趋势有效”。

## 8. 最强反例与停止条件

| 反例 / 否定路径 | 需要看到什么 | 应作决定 |
|---|---|---|
| 原生代理已经会选择 | B0 在同样资源下已能定位关键帧/选择有效试验，H 无实质改善 | 不实施选择器；保留现成代理 |
| 只是更好的输入表示 | B1 接近 H，而两者优于 B0 | 采用最小摘要工程即可；撤回选择算法主张 |
| 只是多看一次 | B2 固定/随机与 H 相当，或把 H 的额外成本计回后优势消失 | 不实施复杂规则；优先简单探测或不探测 |
| 产品本身已有按需视频查询 | 原生 agentic video 达到同等结果 | 不能把选帧叫创新；只有独立物理试验分配仍可能有待测差异 |
| 信息无法恢复 | 相同可用观测无法区分历史接触/未接触 | 保留 `indeterminate`；先修记录/观测设计，不能靠选择器补事实 |
| 无关不确定性 | 探测降低了位置/语言不确定性，却不改变下一步动作或可信验收 | 信息增益目标不匹配任务价值；停止以熵下降代替效果 |
| 动作或部署才是瓶颈 | 失败集中在标定、关节语义、手型适配、控制入口或不可达初态 | 修工程问题，不新增认知框架 |
| 隐藏资源解释全部收益 | H 独占传感器/人工标签/离线试验/推理量，或把重复接触藏在工具里 | 比较无效；不能把混杂效果算作选择收益 |
| 只在挑选后的样本有效 | 自然混合分布中总体成本更高；无歧义时浪费调用，无法恢复时反复查询 | 缩小适用范围或不实施，不宣传普遍优势 |
| 验收可靠性退化 | 成本降低但误验收超预注册界限；或未知样本增加而未计 | 不能宣布更便宜的“可信”成功 |

## 9. 有边界的后续建议

当前选择是 **no-go：不开发新算法**。允许保留后续研究候选，但需先取得以下现实证据：完整同步视频/状态与记录健康审计；自然失败中接触歧义的占比及成本；至少一类由现有工具确实恢复的歧义；同资源强代理仍会选择失误的案例；独立验收的已知误差范围。当前这些不是已知事实，本票也没有填造样本。

若这些门槛在另行安排的证据审计中成立，再注册第6—7节的比较，先复用现成代理、简单摘要和固定/随机规则。只有 H 对这些强对照有可归因增益，才值得把一个最小选择规则做成候选；不先引入世界模型、技能库、多代理或训练平台。若门槛不成立，结论就是“该方向没有足够增量，不实施”，无需为了论文形式继续加模块。

潜在产出也要分层：发现信息不可恢复是观测边界结果；B1 足够是表示/工程结果；B2 足够是减法结果；H 稳定降低成本且验收非劣才支持选择策略实证结果。上述任一结果均不自动构成跨技能自进化或新控制理论。
